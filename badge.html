[Fonctionnement Transparent]

Le script lit automatiquement window.location.href. Vous n'avez jamais besoin de generer manuellement un lien pour chaque nouvel article publie.

Le partage respecte integralement la politique de neutralite technique et l'article 29 de la Loi sur le droit d'auteur du Canada (politiques.html).

[Guide Pedagogique des Reglages & Conformite]

Ce tableau vous resume les elements indispensables et les options de personnalisation avancee pour garantir une utilisation sereine et conforme :

Parametre / Attribut Statut Role & Impact Valeur par defaut
https://.../politiques.html [OBLIGATOIRE] Mention d'utilisation equitable (art. 29 LDA Canada). Protege la neutralite juridique du media. Verrouillee et active
data-url [AUTOMATIQUE] Detecte dynamiquement l'URL de l'article via window.location.href. Peut etre surchargee si besoin. URL courante du navigateur
data-theme [RECOMMANDE] Choix de l'ambiance visuelle : dark (noir), light (blanc), glass (verre), paper, auto. dark
data-style [RECOMMANDE] Format d'affichage : card (carte complete), banner, pill, compact, floating. card
data-title [OPTIONNEL] Titre personnalise affiche en tete de badge. "Partage Citoyen & Educatif"
data-show-socials [OPTIONNEL] Affiche la barre de raccourcis directs vers Bluesky, Mastodon, X, Threads et Email. false
data-show-eink [OPTIONNEL] Bouton de transfert rapide vers liseuses E-Ink (Kobo, Kindle, reMarkable). false

[Guide d'Integration CMS]

[WordPress]

Collez le code dans un bloc « HTML personnalise » en fin d'article ou dans le template single.php de votre theme.

[Ghost CMS]

Ajoutez le code dans un bloc HTML Card ou dans Code Injection (Footer) de votre publication.

[Substack]

Inserez le lien direct ou le bouton personnalise dans votre pied de lettre d'information.

[Webflow / Drupal / Custom]

Ajoutez le bloc Embed HTML dans votre gabarit d'article dynamique.
