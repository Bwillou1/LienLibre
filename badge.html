💡 Comment ça fonctionne ?

Le script lit automatiquement window.location.href pour chaque article. Vous n'avez jamais besoin de générer manuellement un lien pour chaque nouvel article publié.

Chaque clic nettoie les balises mouchards (UTM, Facebook Tracking) et garantit un partage équitable et intègre à vos lecteurs.

📚 Guide d'Intégration Express par Plateforme

🌐 WordPress

Collez le code dans un bloc « HTML personnalisé » en fin d'article ou directement dans le fichier single.php / modèle de votre thème.

👻 Ghost CMS

Ajoutez le code dans un bloc HTML Card ou dans les paramètres Code Injection (Footer) de votre publication.

✉️ Substack

Insérez un lien direct ou utilisez le bouton compact stylisé avec le format miroir LienLibre.

🧱 Webflow / Drupal / Custom

Ajoutez l'élément Embed HTML à l'endroit désiré de votre template d'article dynamique.
