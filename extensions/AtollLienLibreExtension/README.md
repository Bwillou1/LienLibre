# 🏝️ LienLibre Atoll Dynamic Island Extension

Extension officielle de **LienLibre** pour l'écosystème [Atoll](https://github.com/Ebullioscopic/AtollExtensionKit).

## 🚀 Fonctionnalités
- **Dynamic Island / Live Activity** : Affiche en temps réel l'analyse de sécurité Mini-Bot Sentinel, le score de confiance, et le lien déverrouillé directement dans l'encoche de votre MacBook.
- **Liquid Glass UI** : Intégration esthétique native aux styles Frosted Glass d'Apple et Atoll.
- **Support Lock Screen & Minimal Compact Notch** : Visibilité continue lors du traitement de requêtes lourdes ou d'alertes de sécurité DNS.

## 📦 Intégration
Ajoutez ce paquet dans votre projet Atoll via Swift Package Manager :
```swift
.package(url: "https://github.com/Bwillou1/LienLibre.git", branch: "main")
```
