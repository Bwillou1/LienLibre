# Code de conduite — LienLibre

LienLibre est un projet citoyen. Les contributions doivent rester respectueuses, constructives et orientées vers l’accès à l’information, la sécurité et l’intérêt public.

## Comportements attendus

- Respecter les autres contributeurs.
- Argumenter les désaccords avec des faits.
- Éviter le harcèlement, les attaques personnelles et les propos discriminatoires.
- Signaler les vulnérabilités ou abus de manière responsable.
- Garder la sécurité des utilisateurs comme priorité.

## Comportements interdits

- Aider à utiliser LienLibre pour du phishing, malware, spam, fraude ou harcèlement.
- Publier des données personnelles.
- Contourner volontairement les protections anti-hameçonnage.
- Ajouter des domaines douteux à la whitelist sans justification.

## Application

Les mainteneurs peuvent fermer une issue, refuser une contribution ou bloquer un utilisateur si son comportement met le projet ou ses utilisateurs à risque.
